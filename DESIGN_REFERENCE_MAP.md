# BAZAR.UA — Design reference map (Phase A)

Audit date: 2026-11-02. Scope: all **33 original PNGs**, visually inspected after full PNG decoding, including every supporting sheet. Originals remain unchanged. [Machine inventory and SHA-256 hashes](docs/shopify-restoration/evidence.json) records exact filenames and dimensions. All are 1536×1024 except the portrait wireframe (1024×1536). There are 32 unique byte contents: Icons and Modals are duplicates.

## Authority and interpretation

The user's approved reference set is the primary visual source of truth. The old MANIFEST marks every file “CANDIDATE”; that metadata does not override this task's approval of the set. Conversely, approval of the set does not resolve contradictions within it. “FINAL” below records a literal filename/image label, not a newly selected winner. Full page compositions are implementation references; design-system sheets, component sheets, UX architecture and wireframe are supporting references. v1.2 is a plausible newer homepage, **not an authorized resolution** of its differences with v1.0. Resolve C1–C10 before affected implementation; do not redesign or invent missing details.

Six manifest strings fail exact filename matching because of Unicode normalization/encoding differences. Links below use the actual filesystem names, including mojibake and malformed FINAL punctuation. Do not rename originals or use MANIFEST strings as reliable file paths.

Keep Ukrainian UI, layout, colors, Inter typography, spacing, icon stroke, button states, product-card hierarchy and navigation intact within each resolved reference. Implement semantic accessible UI; raster text is not a substitute for editable content. Do not place the design-sheet sidebar, explanatory callouts or miniature page montages into the storefront. Review viewport screenshots against the relevant page region and supporting rules rather than against the entire presentation board.
