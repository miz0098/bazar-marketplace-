# BAZAR Catalog URL Redirects

Catalog modal links use customer-friendly `/catalog/{handle}` URLs. Shopify collection pages remain at `/collections/{handle}`.

Create these redirects in Shopify Admin: `Online Store -> Navigation -> URL Redirects`.

Duplicate catalog labels that share the same handle are listed once.
