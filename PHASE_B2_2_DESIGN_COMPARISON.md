## What the local images show

[Desktop fixture](analysis/shopify-catalog-b2-2/previews/local-desktop.png) and [mobile fixture](analysis/shopify-catalog-b2-2/previews/local-mobile.png) show actual Liquid templates with **prominently labeled synthetic test catalog/media/prices**, native base/header/card scripts and B2.1 CSS. These fixtures are test-only artifacts, not merchant data and not theme content. The screenshots were visually inspected; they demonstrate hierarchy/overflow/state rendering only. They use fallback fonts, inherited dark accents, test media and an unconfigured footer. They do not prove final artwork, CSS cascade in all Shopify contexts, original font delivery or design accuracy.

## Unresolved items carried forward

- **C1:** homepage merchandising order unchanged/deferred.
- **C2:** palette/CTA variants unresolved; existing global defaults still inherit Horizon. No B2.2 setting silently selects a color preset. Sale badge coloring remains provisional for review.
- **C3:** typography-role scale unresolved; card text uses the shared Inter request/fallback and source-based sizing. Catalog H1 inherits native size rather than selecting a conflicting design-system role globally.
- **C4:** container widths/breakpoints/sidebar/card geometry unresolved. Existing container presets remain unchanged. B2.2 exposes adaptive card minimum/sidebar width and an explicitly candidate reference grid for review. No new complete geometry is called approved.
- **C9:** B2.1 shell retained. Mobile catalog filters are accessible disclosure content; final drawer/placement/footer behavior still requires approval. Header's visible design is unchanged by its added accessible name.
- **C7/C8:** original empty-state/illustration exports and complete modal states remain missing. No modal/illustration system invented.

Merchant data/assets, genuine navigation/filter definitions, configured currency/Markets and approved design decisions are necessary for the next visual comparison. Obtain an authorized unpublished development-theme preview and review representative long titles/images/availability/options at agreed viewport widths before accepting visual fidelity. No PDP, checkout, authentication, payment/delivery or account design was implemented here.
