# BAZAR.UA — Storefront design references

This directory is reserved for original storefront design screenshots.

## Source
User-provided `BAZAR Дизайн.zip` (33 PNG files). Originals should be added without re-encoding or visual changes.

## Rules
- Treat screenshots as visual references, not source code.
- Check file versions and conflicting layouts with the project owner before implementing.
- Do not include admin.bazar.ua, staff.bazar.ua or Flutter mobile-app designs in the storefront reference set.
- Do not modify the live Shopify store or merge migration work without explicit approval.
- Codex should audit existing Shopify sources and document restoration plan before editing.

## Upload
Upload extracted PNG files into this directory via GitHub's **Add file → Upload files** interface, committing only to the `design-reference-storefront` branch.
