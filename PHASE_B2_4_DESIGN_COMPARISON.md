## Local review images

[Desktop fixture](analysis/shopify-product-b2-4/previews/local-desktop.png) and [mobile fixture](analysis/shopify-product-b2-4/previews/local-mobile.png) are conspicuously labeled **local simulations**. Product/media/brand/money/policy text is synthetic test input confined to analysis files; none is in theme defaults. Native Horizon picker/form/quantity/recommendation/cart-icon modules and real template paths are exercised. Fonts fall back locally; footer configuration is empty. The images establish composition and test states only, not visual acceptance.

Local inspection found native fixed-basis option labels clipping text; scoped sizing now lets real option names fit/wrap without changing global variant styles. The description overview follows the primary board's real-content column anatomy; absent reviews never become a mock third column. Recommendations intentionally leave missing response slots empty rather than invent products.

## Unresolved design choices

- **C1** homepage merchandising untouched; no product rail/order change outside PDP.
- **C2/C3/C4** remain unresolved exactly as in B2.1/B2.2. No new global palette/container/type preset was selected. Inter request remains the shared foundation; actual delivery is untested.
- **C9** header/footer and existing mobile navigation unchanged. PDP reflow, sidebar and recommendation density must be compared with populated merchant data and approved at the specified viewports.
- **C7/C8** missing illustration/modal exports are not replaced. No fake unavailable-state illustration or image-zoom modal is invented.

Next visual acceptance must use genuine merchant media/content, configured optional fields/apps, existing store currency and approved typography/colors/geometry. Record unavoidable omissions and obtain decisions before correcting them. No remote upload/preview/store setting was authorized or performed here; the named development/published theme IDs were only supplied as future acceptance context.
