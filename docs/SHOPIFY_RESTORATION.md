F16 supersedes the F15 discounted-completion blocker for isolated single-line fixed/exact-percentage checkout only: F5 reuse, atomic test usage/order/payment/shipping snapshot, browser refresh/history and cap contention. Multiple discounted lines, fractional rounding/allocation/stacking and all production financial/provider/auth gates remain blocked. [Scope](F16_DISCOUNTED_CHECKOUT_ACCEPTANCE.md), [ADR0015](adr/0015-discounted-browser-checkout.md).

F15 proves isolated browser no-promo/card confirmation/history with three test carriers. This is not restored production Shopify checkout: discounted completion, actual wallet/provider operations, legal order/inventory lifecycle and real contacts/notifications remain blocked. [Acceptance](F15_BROWSER_CHECKOUT_ACCEPTANCE.md).

F14 advances owned order request/history and isolated return/refund capacity protocols plus ephemeral My Orders return preview. Real order cancellation, return approval/logistics, financial allocations and provider-confirmed real refunds remain mandatory restoration blockers, not completed features. See [ADR0013](adr/0013-order-lifecycle-requests-refunds.md).

Phase F10 expands this commerce checklist to a [44-area source-based gap audit](../FUNCTIONAL_GAP_AUDIT.md), [demo acceptance register](../DEMO_READINESS_CHECKLIST.md) and [completion plan](../DEMO_COMPLETION_PLAN.md). Phase F9 integrates isolated current cart and three-step checkout through typed clients; guest state is never merged. All three carrier test scenarios reach synthetic payment proof, pending confirmation and history. Active-promo settlement, authoritative payable/financial policy, inventory reservation, real order lifecycle, providers, checkout UI rollout and returns/refunds remain mandatory before Demo 100%. See the [explicit readiness matrix](F9_DEMO_READINESS.md) and [ADR 0010](adr/0010-cart-checkout-integration.md).

F6 adds isolated three-step checkout and immutable pending integration-order records (ADR 0006), without live order/provider/inventory activation. F5 adds isolated exact-integer PostgreSQL promotion evaluation and usage-limit tests on top of F3 catalog/cart and F4 session foundations. Live redemption, checkout activation and unapproved business rules remain blocked (ADR 0005). Existing Shopify theme/source remains preserved; neither catalog integration nor the demo checkout replaces Shopify commerce. “BAZAR Demo 100%” must not be claimed until all rows below have reviewed contracts, truthful UI states, failure tests and an approved end-to-end demonstration. Real provider activation additionally requires production approval; a demo may stop explicitly before a real side effect.
