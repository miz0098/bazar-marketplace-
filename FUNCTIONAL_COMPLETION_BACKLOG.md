## Умови закриття задач

Закрити ID можна лише з evidence у поточному commit: actual UI/HTTP/PG, позитивні/негативні/concurrent cases, відомі обмеження та CI. Документ/інтерфейс/SQL table самі по собі не закривають workflow. «Deferred for B» потребує підписаного B01 рішення і не закриває M/P backlog. Кожен staged ID має окремо відмічати test-slice і production-slice; завершення першого не закриває другий.

Не створювати нові гостьові merge правила, новий payment provider, seller funding, rounding чи refund defaults під виглядом технічного виправлення. Відкритий DR — blocker, не дозвіл обрати найзручнішу реалізацію. F18 не розпочинає реалізацію жодної задачі цього backlog.
